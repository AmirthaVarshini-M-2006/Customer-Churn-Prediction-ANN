# Customer Churn Prediction Using ANN

## Project Overview
This project uses an Artificial Neural Network (ANN) to predict whether a telecom customer is likely to leave the service or stay.

## Problem Statement
Customer churn causes revenue loss for telecom companies. This project identifies customers who may leave based on their demographic, service, contract, and billing information.

## Objectives
- Analyze customer data.
- Preprocess the dataset.
- Build a Deep Learning ANN model.
- Predict customer churn.
- Evaluate model performance.

## Dataset
IBM Telco Customer Churn Dataset.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- TensorFlow / Keras
- Google Colab

## ANN Architecture
- Input Layer: Customer features
- Hidden Layer 1: 64 neurons, ReLU
- Dropout: 30%
- Hidden Layer 2: 32 neurons, ReLU
- Dropout: 20%
- Output Layer: 1 neuron, Sigmoid

Optimizer: Adam

Loss Function: Binary Crossentropy

## Evaluation Metrics
- Accuracy
- Precision
- Recall
- F1-score
- Confusion Matrix
- ROC-AUC

## Project Notebook
See `Customer-Churn-Prediction-ANN.ipynb` for the implementation and evaluation.

## Conclusion
This project demonstrates how deep learning can be used to predict customer churn and support customer retention decisions.
